# Security policy

## Supported versions
Only the latest version published on [extensions.blender.org](https://extensions.blender.org/add-ons/ichno/) receives fixes.

## Reporting a vulnerability
Please do **not** open a public issue. Use GitHub's private reporting instead:
**Security ‣ Report a vulnerability** on this repository.

You will get an answer within 7 days. Ichno runs locally, makes no network connection and only writes files
in the output folder you choose, but any report about a crafted .blend file or path handling is welcome.
